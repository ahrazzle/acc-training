# ACC Training

Training materials and interactive demo for ACC.

- `index.html` / `js/` / `css/` / `img/` — static site
- `AGENTS.md` / `IDEA.md` — project notes

## Content

30 views in `js/data.js` (all copy lives there; `js/app.js` renders it):

- Module 0 — ACC from zero (5 views)
- The exposure map (1 view)
- Track 1 — Governance / access (5 views)
- Track 2 — Data management (5 views)
- Track 3 — Integration (5 views)
- Case studies (5 views: 3 synthetic + 1 real deployment)
- Where this is heading — AI (3 views)
- Close (1 view)

## Tests

`npm test` — validates the content layer: nav/view cross-references,
block types, exposure-map pins, table indexes, nav numbering, and
Forma-naming idempotency.
